JSF & MAFIGO SPORT SYSTEMS · 2026
Tecnología para la gestión deportiva

Plataforma base multisport con módulo de Pentatlón Moderno.

Incluye:
- Panel principal
- Atletas, clubes e inscripciones
- Eventos y calendario
- Natación, Esgrima, Obstáculos y Laser Run
- Resultados, aprobación y publicación
- Podios
- Gafetes y reportes preparados
- Simulación nacional
- Control operativo
- PWA
- Red local
- Servidor central local con Python

Para probar el servidor central:
1. Instala Python 3 de 64 bits.
2. Ejecuta iniciar_servidor_central.bat.
3. Abre http://localhost:8080 en la laptop.
4. Desde otros dispositivos de la misma red abre http://IP-DE-LA-LAPTOP:8080.

La puntuación deportiva final debe validarse contra el reglamento y convocatoria aplicables antes de uso oficial.
